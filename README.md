## GitHub Pages
This project is configured for a repository named `ADAM-3000` via `base: '/ADAM-3000/'` in `vite.config.js`.
In GitHub, set Settings > Pages > Source to GitHub Actions.

The NMEA Hypothesis, RIE Omega / Genesis, extraterrestrial influence, multiverse transport, and deity/creator material are fictional product lore. The terrestrial engineering concept is a receive-first CAN/NMEA 2000 observation and interpretation platform.
